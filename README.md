# Question Paper → CSV Converter (Fixed)

This version uses a robust DOCX parser that handles questions split across Word paragraphs, `(a)`–`(d)` options, `Option A:` formats, and missing answers/options.

## Run locally
```bash
pip install -r requirements.txt
streamlit run app.py
```

## Free hosting
Create a GitHub repository, upload `app.py` and `requirements.txt`, then deploy the repository from Streamlit Community Cloud at https://share.streamlit.io/ .
